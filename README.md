# Hawke's Lair

**[orlodax.github.io/HawkesLair](https://orlodax.github.io/HawkesLair/)**

A personal blog, running since 2004. Mostly in Italian, occasionally in
English. 466 posts: short notes, photos, half-formed ideas, travel, and a
handful of long science-fantasy serials.

It started on Blogger, moved to WordPress, and in 2026 became a static site.
Everything ever published is still here, at a stable URL, and no longer
depends on a database staying up.

## Colophon

Built with [Hugo](https://gohugo.io), hosted on GitHub Pages. The design
deliberately follows the blog's long-running WordPress theme (Twenty Fourteen,
dark), down to the typeface and measure, so twenty-two years of posts still
look like themselves.

Set in [Lato](https://www.latofonts.com/) by Łukasz Dziedzic, self-hosted
under the SIL Open Font License.

No cookies, no analytics, no tracking — see [Privacy](https://orlodax.github.io/HawkesLair/privacy/).

## A note on the images

Some posts show *"immagine perduta nella migrazione"* where a picture used to
be. 86 images were already gone before this migration began: they had been
uploaded to two earlier hosts that no longer exist, were absent from the last
server, and were never captured by the Internet Archive. They are not
recoverable. Everything else was pulled down and now lives alongside its post.
